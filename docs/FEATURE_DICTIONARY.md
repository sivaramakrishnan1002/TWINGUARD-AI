# Phase 3 feature and inspection outputs

All rasters use the common EPSG:32644, 30 m grid unless the description says otherwise. The master raster extent includes 2 km around the provisional CMA; CMA-only statistics use the centre-in-polygon mask. Source data in `data/raw` remain unchanged.

| Output | Definition / units | Input and method | Limitations / checks |
|---|---|---|---|
| `data/processed/grid/grid_definition.json` | CRS, 30 m cell size, dimensions, transform, extent, origin and resampling decisions | Current CMA boundary projected to UTM; extent buffered 2 km and snapped to 30 m global origin | Provisional older CMA boundary; confirm final jurisdiction |
| `data/processed/grid/cma_mask.tif` | 1 inside CMA, 0 outside; nodata 255 | Rasterized pixel-centre inclusion, all_touched=false | 1,319,380 cells in the present raster |
| `data/features/terrain/elevation_m.tif` | GLO-30 DSM elevation, metres | Four raw Copernicus DSM tiles bilinearly reprojected | DSM includes buildings/vegetation; unusual negative/coastal values require inspection; source vertical datum EGM2008 |
| `data/features/terrain/slope_deg.tif` | Slope in degrees | 30 m finite difference gradient of elevation | Derivative is grid-scale; inspect edge/nodata effects and steep urban/DSM artifacts |
| `data/features/terrain/aspect_deg.tif` | Aspect in degrees, 0–360 | Gradient orientation | Undefined on flats; current implementation sets a numeric orientation on flat cells |
| `data/features/terrain/curvature_laplacian_per_m.tif` | Laplacian curvature proxy, 1/m | Sum of second x/y derivatives of resampled DSM | Not a geomorphometric standard curvature package output |
| `data/features/terrain/flow_direction_d8.tif` | D8 direction code 1–8; 0 sink/no lower neighbor; 255 nodata | Steepest strictly descending neighbor on unconditioned DSM | Pits/flats not filled; not hydrologically conditioned; code ordering in pipeline script |
| `data/features/terrain/flow_accumulation_cells_d8.tif` | Contributing cell count | D8 routing on unconditioned DSM, cells processed descending by elevation | Treat as exploratory; sink count and coastal/urban DSM artifacts require hydrology review |
| `data/features/terrain/twi_d8_proxy.tif` | `ln(contributing area / tan(slope))`, dimensionless proxy | D8 cell accumulation; slope floor 0.1° | Not standard-library/field-validated TWI; unconditioned sinks can distort it |
| `data/features/landcover/worldcover_2021_class.tif` | ESA WorldCover category code at 30 m | Mode resampling from 2021 v200 10 m source | Built-up class is a built-up-surface proxy, not measured imperviousness; temporal mismatch for historic events |
| `data/features/landcover/worldcover_2021_area_fractions_30m.tif` | 11 bands of fractional area by class (codes 10,20,30,40,50,60,70,80,90,95,100) | Per-class one-hot average from source cells into target 30 m cells | Fractions are cell-area estimates from reprojection; nodata/edge coverage must be considered |
| `data/features/population/worldpop_2021_sum_resampled_30m.tif` | Sum-resampled model population count contribution per 30 m cell | WorldPop R2025A constrained 2021 raster, float32 nodata preserved | Alpha constrained product; CMA sum about 6.2 million is a model estimate and lower than believed 2011 CMA census total; use relative exposure patterns, not absolute headcount |
| `data/features/weather/era5_event_hourly_features.csv` | Hourly precipitation totals/rolling sums 1,3,6,12,24,48,72,168h; temperature, RH, wind, pressure; local and UTC timestamps | Nine Open-Meteo ERA5 points for collected event windows | Reanalysis ~25 km; 9 requested points may share underlying ERA5 grid cells; no gauge truth; CSV because no Parquet engine installed |
| `data/features/weather/daily_era5_nasa_power_comparison.csv` | Daily spatial-mean rain series matched by date | 9-point ERA5 daily baseline and 9 NASA POWER point series | Cross-product spatial means differ in grid/support; not a station validation |
| `data/features/weather/daily_source_comparison.json` | Correlation, bias and RMSE | Matched daily means across 3,287 days | Same caveat as above; NASA POWER parameter unit metadata should be rechecked before publication |
| `data/features/weather/event_peak_rainfall.json` | Maximum 1 h, 3 h, and 24 h rolling rainfall for each event-year and point | Summary derived from the existing hourly feature CSV | ERA5 reanalysis points share coarse model support; not gauge observations |
| `data/features/reservoirs/kaggle_daily_storage_features.csv` | Daily storage, daily/3-day/7-day changes, days since rise, percent of present-day published capacity | Kaggle 4-reservoir daily storage | Current capacity ratios are not historically verified; storage changes are not releases; rainfall field units unverified |
| `data/features/reservoirs/opencity_monthly_storage_tidy.csv` | Long-format monthly storage (mcft by page description) | Six OpenCity lake CSVs with lake names mapped from manifest | Monthly cadence is too coarse for event-day release analysis |
| `data/features/reservoirs/illustrative_track_b_backtest.csv/.json` | Illustrative rule: total storage >=80% current capacity, rising vs 3 days prior, 3-day ERA5 rainfall >= pre-target 2015 P90 | Daily storage and nine-point ERA5 rainfall mean | Exploratory screen; current capacities not historical, no complete event outcome series to validate false alarms, not a release model |
| `data/features/roads/chennai_road_graph.gpkg` | Road segments and directed arcs with OSM identifiers, highway class, direction/access, bridge/tunnel and maxspeed tags; road nodes with degree and sampled DEM height | Local OSM ways/locations, custom graph topology | OSM coverage is incomplete/unknown; segment/node geometry and directed component statistics are approximate; no NetworkX package |
| `data/features/facilities/chennai_facilities.gpkg` | Tagged point/way facilities with nearest-road distance | OSM amenity, emergency, healthcare, shop, tourism, transit/social facility tags | OSM tags/mapping completeness vary; nearest distance is geometric and not travel time |
| `data/features/buildings/chennai_building_footprints.gpkg` | Clipped building outlines and footprint area | OSM building ways | Incomplete mapped footprints; footprint area is not floor area or occupancy |
| `data/features/hydrology/chennai_waterways.gpkg` | Local waterway lines; exact target names from `OSM_WATERWAYS.md` flagged separately | OSM waterway ways clipped to buffered CMA | Mapped network may omit drains/canals; use the existing exact-name inventory for named-waterway checks |
| `data/features/osm/osm_graph_summary.json` | Existing GeoPackage layer counts, road length, highway/facility category counts, and exact target-waterway name count | Read-only inventory summary derived from the local OSM GeoPackage | Graph connectivity was not recomputed in this summary; validate connected components, dangling edges, and routability before routing. OSM completeness is unknown |
| `data/processed/exposure/road_network_100m_buffer_mask.tif` | Unique 100 m road buffer inside CMA | Union-like rasterization of mapped OSM road segment buffers | Proximity only; not road accessibility, evacuation routing, or people actually on roads |
| `data/processed/exposure/facility_500m_union_mask.tif` | Unique union of 500 m circles around mapped facility points | OSM facility point buffers | Not a network service area; gaps in OSM may omit services |
| `data/processed/exposure/osm_facility_500m_population_estimates.csv` | Per-facility population count within 500 m circle and nearest road distance | WorldPop 30 m count-contribution raster and OSM facility points | Overlapping rows must not be summed as unique population; alpha model estimates; no routing/accessibility implied |
| `data/processed/exposure/population_exposure_summary.json` | Unique CMA population sums in road/facility buffer unions and nodata counts | Rasterized OSM buffers intersected with WorldPop grid | Proximity exposure only; alpha constrained model counts, not census headcounts |
| `data/processed/labels_inspection/*EXPLORATORY_NOT_FINAL.tif` | Rasterized Sep/Oct pre-flood references and Nov 12/24 2015 UNOSAT geometries | UNOSAT archive rasterized to grid, pixel-centre method | 12 Nov/24 Nov are not the Dec 1–8 peak. These are inspection layers, not final labels |
| `data/processed/labels_inspection/november_flood_minus_sep_oct_reference_TEST_ONLY.tif` | November rasterized union with any Sep/Oct pre-flood reference cells removed | Simple exploratory subtraction test | PreFlood classes include uncertain wet soil and static water; not validated flood discrimination |
| `data/processed/labels_inspection/label_inspection_summary.json` | Per-layer counts/areas, baseline overlap test, GFD event overlap, OpenCity inventory | Native source metadata plus CMA pixel/feature intersections | GFD is coarse MODIS (~250 m), event ID 4309 centroid is outside CMA; overlap is approximate, not a verified local event mask |
| `data/features/osm/chennai_osm_features.gpkg` | Road segments and directed arcs, road nodes, facilities, building footprints, waterways | OSM Geofabrik South India PBF filtered to CMA + 2 km | Local extraction status and graph metrics to be appended after completion; OSM completeness is unknown and ODbL attribution applies |
